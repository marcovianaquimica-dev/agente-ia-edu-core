FLUXO DE ONBOARDING
================================================================================

1. Director cria convite
   create_invitation(school_id, email, role, scope_*)
   → UserInvitation(status=PENDING, token=random)

2. Email enviado com token

3. User valida token
   validate_token(token)
   → Verifica status=PENDING

4. User aceita
   accept_invitation(token, user_id)
   → status = ACCEPTED

5. User ativa conta
   activate_invitation(token, user_id)
   → Cria UserSchoolLink
   → status = ACTIVATED
   → Token não reutilizável
